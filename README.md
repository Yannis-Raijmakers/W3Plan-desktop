# W3Plan desktop

Hier staan alleen de installers van de W3Plan-desktopapp, voor het team. De broncode staat in de privé-repository.

Download de nieuwste versie onder **Releases**:

- **Mac met Apple silicon (M1 en nieuwer):** `W3Plan-…-mac-arm64.dmg`
- **Mac met Intel:** `W3Plan-…-mac-x64.dmg`
- **Windows:** `W3Plan-…-win-x64.exe`

De `.zip`'s gebruikt de app zelf om bij te werken.

De schoolgegevens zitten niet in de app. Kies bij de eerste start `src/data/schooldata.json` uit de privé-repository.

De app is niet door Apple gekeurd. Op de Mac de eerste keer: Systeeminstellingen → Privacy en beveiliging → Open toch, of in Terminal `xattr -cr /Applications/W3Plan.app`. Daarna werkt de app zichzelf bij.
