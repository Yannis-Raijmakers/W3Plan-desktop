# W3Plan Desktop

[![Latest Release](https://img.shields.io/github/v/release/Yannis-Raijmakers/W3Plan-desktop)](https://github.com/Yannis-Raijmakers/W3Plan-desktop/releases/latest)

**W3Plan** is a Dutch school planning application designed to help students organize their schoolwork, assignments and exams.

This repository contains the official desktop installers for the W3Plan team application.

## Download

Download the latest version from [GitHub Releases](https://github.com/Yannis-Raijmakers/W3Plan-desktop/releases/latest).

| Platform | Installer |
|---|---|
| Windows (x64) | `.exe` |
| macOS (Apple Silicon) | `mac-arm64.dmg` |
| macOS (Intel) | `mac-x64.dmg` |

The `.zip` packages are reserved for the application's built-in updater.

## First-time setup

On first launch, select the `schooldata.json` file provided separately by your W3Plan administrator.

### macOS

The application is currently not notarized by Apple. macOS may display a security warning on first launch. You can review the warning and use **Open Anyway** under System Settings → Privacy & Security.

## Updates

W3Plan checks GitHub Releases for new versions and supports in-app updates.

## Source code

The application source code is maintained in a separate private repository. This repository is dedicated to distributing desktop releases.
